## To avoid merge conflicts on GitHub
This is not a bulletproof method; however, this should minimise the occurrence of merge conflicts. 

- In your group repository, create a folder for each feature or task that your group is interested in. Assign one person as the primary contributor for each feature or task. Each person can create their own branch to work on a specific feature or task, and then merge their changes into the main branch.
- If multiple people want to contribute to the same feature or task, communication is the key. Use issues to coordinate and make sure that everyone is aware of what others are working on.
- Additionally, it is essential to pull, commit, push, and create Pull Requests regularly. This can help avoid merge conflicts, and even if a conflict does occur, it will likely be small and easily addressed.

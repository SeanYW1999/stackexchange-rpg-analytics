# Group project part 3
Hint - To avoid merge conflicts on GitHub

This is not a bullet proof method, however, this should minimise the occurrence of merge conflict. In your group repository, create a folder for each feature or task that your group are interested in. Assign one person as the primary contributor for each feature or task. Each person can create their own branch to work on a specific feature or task, and then merge their changes into the main branch.

If multiple people want to contribute to the same feature or task, communication is the key. It's important to make sure that everyone is aware of what others are working on and to coordinate changes to avoid conflicts.

Additionally, it's important to regularly pull changes from the main branch to ensure that everyone is working with the latest version of the code. This can help to avoid conflicts that can arise when changes are made to the same file by different contributors.
